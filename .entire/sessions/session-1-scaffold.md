## Errors Encountered & Fixes

### 1. `create-next-app` refused to scaffold into existing directory

**Error:**  
```
The directory bookmarks-app contains files that could conflict:
  .claude/  .entire/  .gemini/  README.md
```

**Cause:** `create-next-app` blocks scaffolding if any files exist in the target directory.

**Fix:** Scaffolded into a temporary subdirectory `./nextjs-scaffold`, then moved all files to the root with `Move-Item`, and removed the temp dir.

---

### 2. Login redirecting to `/error` immediately

**Symptom:** After submitting credentials at `localhost:3000/login`, the app redirected to `localhost:3000/error` showing "Sorry, something went wrong".

**Root cause:** `@supabase/ssr` v0.10.x (installed) broke backwards compatibility with the code style generated by older `create-next-app` templates:

- `CookieOptions` was **removed** from `@supabase/ssr` exports
- `cookies()` from `next/headers` became **async** and must be `await`ed
- Therefore `createClient()` in `utils/supabase/server.ts` needed to be `async`
- All call sites (`actions.ts`, `page.tsx`, route handlers) needed `await createClient()`

Additionally, the middleware did not include `/error` in its bypass list, causing an infinite redirect loop when auth failed.

**Fixes applied:**
- Rewrote `utils/supabase/server.ts` → async factory, `await cookies()`
- Rewrote `utils/supabase/middleware.ts` → removed `CookieOptions`, added `/error` to bypass
- Added `await` to every `createClient()` call across 5 files
- Updated `app/error/page.tsx` to surface the real error message via `?message=` param for debugging

---

### 3. `git push` blocked by GitHub secret scanning

**Error:**
```
remote: - GITHUB PUSH PROTECTION
remote:   — Supabase Secret Key ——
remote:   locations:
remote:     - commit: 5997588 path: .env.local.example:1
```

**Cause:** `.env.local.example` was created with the actual Supabase/Resend keys as "placeholders", which GitHub correctly detected as real secrets.

**Fix:**
1. `git rm --cached .env.local.example` — removed from tracking
2. Replaced all real values in `.env.local.example` with safe placeholder strings (`your-anon-key`, etc.)
3. `git commit --amend --no-edit` — rewrote the commit so secrets never appear in history
4. `git push` — succeeded

## Final State

### Auth Flow
```
User visits any route
  └─> middleware.ts checks Supabase session
        ├─> No session → redirect to /login
        └─> Session exists → allow through

/login
  ├─> "Log in" button  → login() server action → signInWithPassword → redirect /
  └─> "Sign up" button → signup() server action → signUp → redirect /

/ (home)
  ├─> Shows "Logged in as: <email>"
  └─> Logout button → signOut() server action → redirect /login
```
